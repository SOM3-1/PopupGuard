# PopupGuard Privacy Policy (Template)

Last updated: February 22, 2026

## Overview

PopupGuard is a browser extension that helps reduce website popups such as promo popups, login prompts, and cookie banners.

PopupGuard is designed to work locally in your browser.
PopupGuard is a user-controlled tool and should be used at your own discretion.

## What PopupGuard Collects

PopupGuard does not collect, sell, or share personal information.

PopupGuard does not send browsing data to a server.

PopupGuard does not use analytics, tracking pixels, or remote logging.

## What Data Is Stored Locally

PopupGuard stores settings in your browser so the extension can remember your choices.

This may include:

- Whether PopupGuard is enabled or disabled
- Which popup types are enabled (promo, login, cookies)
- Cookie mode setting (`Strict`, `Balanced`, `Off`)
- Disabled sites list (sites where PopupGuard should not run)
- A local debug record of the most recent action (used only for troubleshooting inside the extension UI)

This data is stored using the browser extension storage APIs (`storage.sync` and `storage.local`).

## Website Access

PopupGuard runs on websites you visit so it can detect and close popup overlays.

PopupGuard reads page content only to identify popup elements and buttons (for example, close, reject, decline, preferences).

PopupGuard does not transmit page content outside your browser.

## Cookies and Consent Popups

PopupGuard may interact with cookie consent popups based on your settings.

PopupGuard is designed to prefer privacy-preserving actions (such as reject, decline, or essential-only) when available and does not automatically accept cookies by default.

## Third-Party Services

PopupGuard does not rely on third-party servers or cloud APIs for popup detection.

## Data Retention

Settings remain stored in your browser until you:

- Change them in the extension UI
- Clear browser extension storage
- Uninstall the extension

The debug record (last action) can be cleared from the extension UI.

## Security

PopupGuard is designed to process data locally in the browser and minimize stored data.

No software is perfect. If you discover a security issue, please contact:

## Disclaimer

PopupGuard is provided as-is to improve browsing convenience.

PopupGuard may not work on all websites and may affect page behavior on some sites.

Users should disable PopupGuard on any site where they prefer manual control or where the extension causes issues.
